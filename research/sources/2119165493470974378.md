Another great visibility hack for your SaaS is to get listed on Vercel's http://skills.sh (DR 82). You get a dedicated page with your skill, its install command and an install counter.

Here is how:

1. Write an agent skill for your SaaS, a SKILL.md that tells the agent how to use your API (ask Claude to do it for you).
2. Put it in a public GitHub repo.
3. Run npx skills add your-org/your-repo once.
